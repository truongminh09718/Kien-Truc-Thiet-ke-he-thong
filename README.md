# AutoLux

Giao diện website bán xe responsive bằng HTML, CSS và JavaScript thuần.

## Chạy bản xem trước

Mở `index.html` trực tiếp trong trình duyệt, hoặc dùng một máy chủ tĩnh bất kỳ tại thư mục này.

Ví dụ với Node.js:

```powershell
npx serve .
```

## Tính năng có thể thử

- Lọc kho xe theo hãng, kiểu dáng, nhiên liệu và từ khóa.
- Chọn tối đa hai xe để so sánh.
- Mở chi tiết xe.
- Thử màu và góc xem trong khu vực showroom 360°.
- Điều chỉnh giá xe, tỷ lệ trả trước và thời hạn vay.
- Điền quy trình đặt lịch lái thử ba bước.
- Mở trợ lý tư vấn dạng chat.
- Menu và thanh hành động riêng cho thiết bị di động.

Hình ảnh trong bản demo tải từ Wikimedia Commons và Unsplash, vì vậy cần kết nối mạng để hiển thị đầy đủ.
